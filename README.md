### 🚀 &nbsp;Projects

**[JobHunt](https://github.com/tanishqaryan9/Job-Posting)** &nbsp;—&nbsp; *Spring Boot · Flutter · Redis · Kafka · Docker · MySQL*
> Full-stack job platform connecting blue-collar workers with local employers. Features RESTful CRUD APIs with Spring Security auth, Redis caching for faster responses, event-driven notifications (Kafka → Spring Events in production), and Docker-based CI/CD on Render.

**ReachClock** &nbsp;—&nbsp; *Flutter · Dart · Firebase · Geolocation APIs*
> Location-aware alarm app that triggers when you're near your destination — built for commuters who miss their stop. Real-time GPS tracking, configurable proximity radius, Firebase Auth, and cross-platform UI for Android & iOS.

**[Tech Buddy](https://github.com/tanishqaryan9/Tech-Buddy)** &nbsp;—&nbsp; *Python · Ollama · Google Gemini API · Tkinter*
> AI desktop assistant integrating a local LLM (Ollama) and Gemini API to guide users through device tasks via interactive visual overlays (arrows, highlights, tooltips). Built for accessibility. **Top 10 at Hackathon.** 🏆

**Trip Expense Splitter** &nbsp;—&nbsp; *C · Raylib · RayGUI · SQLite*
> Desktop expense manager with a greedy debt-settlement algorithm built on a custom dual priority queue (min-heap + max-heap) in C. Features an interactive draggable debt graph rendered with custom trigonometry, and SQLite-backed trip persistence.
